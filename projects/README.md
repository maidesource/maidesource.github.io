# Featured Project: Personal Portfolio Website

This portfolio website ([maidesource.github.io](https://maidesource.github.io)) is itself the
technical project showcased here, since it was designed and built from scratch rather than
generated with a website builder.

## What it demonstrates

- **Semantic HTML5** structure (`header`, `main`, `section`, `footer`) for accessibility and
  clean markup.
- **Custom CSS** written from scratch: CSS variables/color palette, Flexbox-based layout,
  responsive card components — no CSS framework used.
- **Vanilla JavaScript**: DOM event listeners and smooth-scroll navigation, implemented without
  any external library.
- **Git & GitHub workflow**: the site is version-controlled and deployed automatically via
  GitHub Pages on every push to `main`.

## File overview

| File | Purpose |
|------|---------|
| `../index.html` | Page structure and content |
| `../styles.css` | Visual design (colors, layout, typography) |
| `../script.js` | Smooth-scroll navigation behavior |
| `../docs/cv.pdf` | CV, generated from `cv.tex` with LaTeX (pdflatex) |
| `../docs/cv.tex` | LaTeX source of the CV |
| `../assets/` | Profile photo and other images |
