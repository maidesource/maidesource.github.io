# Maide Oskay: Personal Portfolio

Source code and content for my personal portfolio website, live at https://maidesource.github.io

This repository was built for a university course assignment that simulates preparing a
technical portfolio for a working student position application.

## Structure

- `index.html`, `styles.css`, `script.js`: the website itself
- `assets/`: images used on the site
- `docs/`: CV, provided both as a compiled PDF and its LaTeX source
- `projects/`: documentation of the technical project showcased in the portfolio
